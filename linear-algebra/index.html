Linear Algebra

A matrix is a machine that moves vectors. Linear algebra is learning to read that machine: first by what it does to the grid, then by what it reaches and what it crushes, then by the directions it leaves alone.

Before this leaf: grid coordinates, arithmetic and Pythagoras.
This leaf feeds: Statistics and data, Differentiation.
Objects you will meet again: the 3-4-5 triangle, the two towns, the dial, the fifteen.

Glossary

vector page 01
A size and a direction given together; drawn as an arrow, written as a list of components.
span page 02
Every point you can reach by adding and scaling some arrows.
independent page 03
An arrow the others cannot reach; only the zero recipe makes zero.
basis page 04
The smallest set of arrows that reaches everything.
dot product page 05
One number that says how much two arrows agree; zero when they are perpendicular.
matrix page 06
A machine that moves every arrow and keeps the grid straight; its columns say where the basis arrows land.
determinant page 09
How much the machine stretches area; negative means a flip, zero means the plane collapses.
system page 10
The question: which input does the machine send to b?
inverse page 11
The machine that undoes A; it exists only when the determinant is not zero.
elimination page 12
Row moves that change the equations without changing the answer.
rank page 13
The dimension of what the machine reaches.
projection page 14
The closest point in a subspace; its error is perpendicular.
least squares page 15
The nearest reachable answer when no exact one exists.
orthonormal page 16
Perpendicular arrows of length 1.
eigenvector page 17
An arrow that keeps its direction when the machine moves it.
eigenvalue page 17
The number λ that says how much a matrix stretches its eigenvector: Av = λv.
symmetric page 19
A matrix equal to its transpose; it stretches along perpendicular axes.

For the teacher

Sequencing and rationale

Four parts. Part I builds with vectors (span, independence, basis, dot product) so that Part II can read a matrix as a machine described by its columns. Part II runs machine, product, composition, determinant, systems, inverse, elimination, and the four subspaces, in the order need before tool: systems are asked before the inverse answers them. Part III brings length and angle back for projection, least squares and orthonormal bases. Part IV reads the machine on its own axes and ends with SVD, where the shear that defeated eigenvectors gives in. Two house matrices, S and the shear H, recur from page 6 to page 20.
