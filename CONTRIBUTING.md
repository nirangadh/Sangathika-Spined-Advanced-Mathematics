# Contributing to සංගතික · Sangathika

Thank you for helping. Every lesson on [www.sangathika.com](https://www.sangathika.com/) follows one method: one idea per lesson, act before you read, predict before the answer is shown, and a few objects that return across the subjects with new meaning. The [about page](https://www.sangathika.com/about/) describes it.

## Report an error

Open an issue. Name the lesson and, if you can, the demo or question, and say what is wrong. Each confirmed error is fixed and noted in the change log.

## Propose a lesson or an application

Open an issue with:

1. The idea in one sentence of fewer than twenty words, with at most one new term.
2. What the learner does first, before the idea is named.
3. The common mistake the lesson clears.
4. The question it hands on to the next lesson.
5. The lessons it builds on.
6. For an application: which lessons, in which subjects, it needs.

## Pull requests

Pull requests are welcome after an issue has agreed the change. Plain HTML, CSS and JavaScript only, with no framework, library or third-party request. `python3 tools/check.py` must pass. Every HTML, JavaScript, CSS and SVG file carries the licence header used in the existing files. Illustrations are original inline SVG. No raster images, no stock art, no copied text.
